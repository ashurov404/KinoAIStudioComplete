# Kino AI Studio V6 — Own 3D Core

V6 introduces a dependency-free TypeScript software 3D core for the preview path. It does not import Three.js, Blender, Unity, Unreal, or a third-party video-generation model.

Layers:
1. scene graph/data
2. procedural geometry
3. camera projection
4. triangle rasterization
5. material + Lambert lighting
6. character motion
7. environment generation
8. future physics/facial/lip-sync modules
9. frame sequence / encoder boundary

This is an own software-rendering foundation, not a claim of finished photorealistic cinema. Production photorealism requires substantially more geometry, materials, global illumination, temporal rendering, animation, physics, and compute work.
